# Blue Planet — Ocean Life & Marine Conservation

A responsive student website built with basic HTML, CSS and JavaScript.

## Files
- `index.html` — page structure and content
- `style.css` — layout, colors, responsive design and animations
- `script.js` — navigation, species filters, action checklist, pledge form, quiz and back-to-top button

## How to run
1. Download and extract the ZIP.
2. Open the folder in Visual Studio Code.
3. Open `index.html`, then click **Go Live** if you have the Live Server extension installed. You can also open `index.html` directly in a browser.
4. An internet connection is needed for the online photos and Google Fonts.

## Interactive features
- Mobile navigation menu
- Filter marine species by conservation label
- Checklist with a progress bar
- Pledge form with a live confirmation and session-only counter
- One-question quiz with feedback
- Back-to-top button

## Notes
- The pledge counter is only stored in the current page session; this is a front-end demo and does not submit data to a server.
- Species conservation labels are illustrative. Check the IUCN Red List for the current status of a specific species or population.
- Images are loaded from Unsplash URLs and need an internet connection.
